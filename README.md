# Kirapara News

Kirapara News は、きらめきパラダイス / 以闪亮之名 / Life Makeover / 스타일라잇 の公式ニュースやSNS投稿をまとめて閲覧するための非公式PWAです。

## 主な機能

- 日本 / 中国 / 韓国 / Global のニュースを統合表示
- 公式サイト、X、Weibo、Bilibili、TapTap、好游快爆など複数ソースの収集
- AIによる日本語翻訳・要約
- 記事画像のインライン表示と画像ビューア
- X画像は可能な限りオリジナル画像を取得
- 長い縦画像は全幅表示のまま縦スクロール
- 通常サイズの画像はビューア中央に配置
- Android / PWA の戻る操作で画像ビューアやメニューを先に閉じる
- 画像ビューアを閉じた後のページスクロールを維持
- ライト / ダークテーマ
- PWAとしてホーム画面に追加可能
- GitHub Pagesで公開

## 画像ビューア

画像ビューアでは、通常の画像は実際の visual viewport を基準に上下中央へ配置します。CSSの `100dvh` による中央寄せは Android WebAPK で安定しなかったため、画像の縦横比と実際の表示領域から JavaScript で通常画像 / 長尺画像を判定し、通常画像は `top: 50%` / `left: 50%` で明示的に中央へ配置します。極端に縦長の画像は上端から表示して、そのまま縦スクロールできます。

Android / Chromium WebAPKで、ビューアを閉じた後に背景やナビゲーションが残る問題を避けるため、閉じたビューアはDOMから完全に破棄して次回表示時に再生成します。また、ビューア表示時に本文を `overflow: hidden` で固定しない構成に変更し、履歴のスクロール復元も manual にして、閉じた後のスクロール慣性低下を防いでいます。

X画像については `pbs.twimg.com` の画像URLを `name=orig` に正規化します。DOM全体を監視して画像URLを書き換える MutationObserver は廃止し、カードやビューアの画像候補生成時だけ正規化することで、Androidでのスクロール負荷を抑えています。

## データ更新

ニュースデータはGitHub Actionsと収集スクリプトから更新されます。画面上部の「最終更新」は記事の投稿時刻ではなく、最後にクロールした時刻を表示します。

## AI処理

収集済みの記事について、日本語翻訳と要約を生成します。AIの出力には誤りが含まれる可能性があります。

現在のローカルAI処理系では Gemma 4 E4B / LiteRT-LM を利用する構成を前提としています。
